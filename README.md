Simple [Astro](https://github.com/withastro/astro) static site for the [MIT DUSP Spatial Analysis & Action Lab](https://mit-spatial-action.github.io/) (or SAARG).

## Set Up a Development Environment

1. Clone the repo.
2. `npm install`
3. `npm run dev`
4. Make a cup of tea.
